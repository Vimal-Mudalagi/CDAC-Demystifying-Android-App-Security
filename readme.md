Practical work and study material from the **Demystifying Android Application Security** programme by **C-DAC / FutureSkills PRIME**.

The repository contains Android security assignments, lab work, theory notes, tools, reports, and practical exercises completed during the programme.

## 📖 What This Repository Contains

This repository is intended as a record of:
- Practical assignments
- Lab exercises
- Security analysis reports
- Command references
- Frida scripts
- Decompiled/decompiled-analysis notes
- Theory material
- Screenshots and supporting evidence

The focus is on understanding how Android applications work, how security weaknesses can be identified, and how runtime behaviour can be analysed.

---

## ⚠️ Disclaimer

All security testing in this repository was performed against:
- Intentionally vulnerable applications
- OWASP security challenges
- Course-provided applications
- Personal/local lab environments

The material is intended for educational and authorized security testing only. Do not use these techniques against applications or systems without permission.
